# yemen-electronic-marketplace

# 🛒 منصة يمن إلكترونيك (Yemen Electronic) — سوق رقمي متكامل للتجارة الإلكترونية

منصة تجارة إلكترونية متكاملة وسوق رقمي مخصص لعرض وبيع الهواتف الذكية والأجهزة الإلكترونية، تتيح للمستخدمين والتجار إدارة عمليات البيع والشراء بمرونة وعبر نظام خلفي مؤمن بالكامل.

---

## 🧱 البنية الهندسية والتقنيات المستخدمة (Architecture & Tech Stack)

تم بناء وتطوير المنصة بالاعتماد على أسس برمجية متينة تضمن استقرار النظام وحمايته وتوفير تجربة تصفح سريعة:

* **البيئة البرمجية الأساسية (Backend):** لغة `PHP` لبناء منطق العمل، إدارة الجلسات، ومعالجة الطلبات والعمليات التجارية داخل السوق.
* **تقنية ربط البيانات والأمان:** الاعتماد الكامل على المعيار الحديث `PHP PDO (PHP Data Objects)` لبناء استعلامات آمنة ومحكمة تمنع الاختراقات.
* **إدارة قواعد البيانات:** تصميم وهيكلة قاعدة بيانات `MySQL` متطورة لحفظ بيانات المنتجات، تصنيفات الهواتف، سجلات المستخدمين والمبيعات.
* **الواجهات الأمامية (Frontend):** واجهات مستخدم متجاوبة (Responsive UI) لمتجر إلكتروني مبنية باستخدام `HTML5` و `CSS3` مع إطار العمل `Bootstrap` لتسهيل تصفح الأجهزة والالكترونيات من أي جهاز.

---

## 💎 الميزات التقنية والأمنية للنظام (Key Technical Features)

* **هندسة المعالجة الآمنة (Prepared Statements):** معالجة كافة عمليات البحث، تصفية الهواتف، والطلبات عبر السيرفر باستخدام الاستعلامات المجهزة في PDO لحماية السوق بالكامل من ثغرات الحقن البرمجي (`SQL Injection`).
* **إدارة المنتجات والمخزون الإلكتروني:** نظام خلفي مرن يتيح إضافة الأجهزة الإلكترونية، تحديد مواصفاتها (مثل نوع الهاتف، السعر، الحالة)، وتنظيمها داخل تصنيفات ذكية.
* **نظام رفع ومعالجة صور الأجهزة (Secure File Upload):** آلية برمجية آمنة تتيح للمعلنين والتجار رفع صور الهواتف والالكترونيات بدقة عالية مع فحص الامتدادات وتوليد أسماء فريدة لمنع التداخل على السيرفر.
* **تأمين حقول المستخدمين وجلسات الشراء:** نظام مدمج لتشفير بيانات الحسابات وحماية حقول الإدخال لضمان خصوصية عمليات البيع والشراء.
